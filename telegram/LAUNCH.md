# Pump it — запуск у Telegram (Kraken Ukraine)

У цій папці:
- `index.html` — сама гра, один файл
- `bot.py` — мінімальний бот: кнопка «Грати» і закріплений пост у гілці
- `pinned-post.txt` — текст закріпленого поста, якщо публікуєш вручну

---

## Крок 1. Викласти гру за посиланням (GitHub Pages, безкоштовно)

1. Зайди на github.com → **New repository** → назва `pump-it` → **Public** → Create.
2. **Add file → Upload files** → перетягни `index.html` → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
4. За 1–2 хвилини гра буде доступна за адресою:
   `https://<твій-логін>.github.io/pump-it/`

Це посилання можна одразу кидати людям для демо: воно працює в будь-якому браузері на телефоні й комп'ютері, з голосом (браузер попросить доступ до мікрофона) і кнопкою «Поділитися».

## Крок 2. Бот і Mini App

1. У @BotFather: `/newbot` → назва → username (наприклад `PumpItKrakenBot`). Збережи **токен**.
2. `/newapp` → обери цього бота → назва, опис, картинка 640×360 →
   **Web App URL** = посилання з кроку 1 → **short name**, наприклад `play`.
3. Пряме посилання на гру: `https://t.me/<bot_username>/<short_name>`

## Крок 3. Прописати бота в грі

Відкрий `index.html`, знайди на початку скрипта:

```js
const TG_BOT = "PumpItKrakenBot";
const TG_APP = "play";
```

Заміни на свої значення → завантаж оновлений `index.html` на GitHub (Upload files з заміною).
Після цього QR-коди на картках вестимуть у твою гру з ніком того, хто поділився.

## Крок 4. Гілка в групі

1. Налаштування групи → **Topics** → увімкнути.
2. Створити гілку, наприклад «🎮 Pump it».
3. Додати бота в групу і дати права адміна: надсилати й закріплювати повідомлення.

## Крок 5. Закріплений пост

**Варіант А, без коду:** опублікуй у гілці текст з `pinned-post.txt` разом із посиланням на гру і закріпи його вручну.

**Варіант Б, з ботом (красива кнопка під постом):**

```bash
pip install requests
export BOT_TOKEN="токен_від_BotFather"
export BOT_USERNAME="PumpItKrakenBot"
export APP_NAME="play"
python bot.py
```

Напиши `/post` в гілці «🎮 Pump it» (від адміна). Бот опублікує пост із кнопкою «Грати», закріпить його і видалить твою команду.
Для постійної роботи бота підійде будь-який сервер, Railway чи Render.

---

## Перевірити перед запуском

- [ ] Голос усередині Telegram на **iPhone** і на **Android**. Якщо мікрофон недоступний, гра сама перемикається на утримання.
- [ ] Посилання з `?startapp=ref_нік` відкриває гру на телефоні і на **Telegram Desktop (Mac)**.
- [ ] Kraken погодив назву, логотип, призи і правила.
- [ ] Спільний лідерборд: зараз рекорди зберігаються на кожному пристрої окремо. Для спільного топу групи потрібен сервер або вбудована в Telegram платформа ігор для ботів.
